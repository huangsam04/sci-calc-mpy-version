# 内存、动效与版本分支

先完成入口和绘图工作，再用 COM5 的最大受支持状态连续五轮测量最低空闲堆、输入到可见提交、单 step、绘制帧和堆漂移。只处理 1--3 个可稳定复现的热点。

## 动效硬门禁

- [ ] 真机最大状态的最低空闲堆不小于 12 KiB，且连续五轮 `MemoryError=0`。
- [ ] 一个 8192 B framebuffer、0 B 新像素缓冲、固定动效状态不超过 64 B、逐帧分配为 0。
- [ ] 按键或逐帧路径不调用 `gc.collect()` / `gc.mem_free()`；异常、新输入或低内存时立即恢复正常亮度并吸附终态。

只在三个门禁全部通过后实现以下两项，且复用现有 `FrameScheduler`、`DamageMap`、`Renderer` 和 SSD1322 固定命令缓冲：

- [ ] 菜单高亮短距离 ease-out 滑动，只更新旧行、新行和经过行。
- [ ] 120--160 ms SSD1322 master-current 页面淡出/淡入；暗点只提交一次目标页。

若门禁或时延预算失败，优先保留菜单滑动；仍不达标则两项均不启用，不得降低 12 KiB 门槛或保留已知风险。未发布版本没有兼容义务，因此只有在真机测量证明收益时才删除直接造成常驻压力的旧兼容路径。
